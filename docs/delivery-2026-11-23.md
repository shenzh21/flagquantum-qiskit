# 2026-11-23 仓库更新

本次将此前本地 GPU 接入、benchmark、独立审查与两项测试工具修复一并纳入仓库。包版本仍为 0.2.0；这是源码提交，不是新的 PyPI 或 wheel 发布。历史报告和验证构建里的 README 保持当时语境，“尚未推送”不表示本次源码仍缺少对应实现。

## 已纳入

- 单卡 NVIDIA CUDA，single/double；Windows Triton 默认路线与依赖诊断。生产量子数值继续只使用真实 FlagQuantum，不存在 Aer/CPU 静默 fallback。见 [GPU 安装与边界](../GPU.md)。
- 固定来源 QASMBench 三个小型实例、隔离进程对照、CPU/GPU 与精度边界、原始失败记录。小线路没有 GPU 加速结论。见 [benchmark](../benchmarks/README.md)。
- [独立完整审查](../AUDIT-2026-11-23.md)及其证据。该报告冻结于修复前，不改写审查当时发现。
- F2 已修复：任一侧 single 的跨引擎比较使用 `5e-5`，double/double 保持 `1e-10`；每侧独立参考仍按自身精度判断。这是本项目验证标准，不是 Aer 官方统一容差。
- F3 已修复：用户线路报告自动使用 UTC 微秒时间戳；JUnit/benchmark 复现命令也使用时间戳，不覆盖旧证据。

## 仍待解决

[Issue #1](https://github.com/shenzh21/flagquantum-qiskit/issues/1) 跟踪 F1（未修复）：默认优化级别 2/3 可将完整 save/set 指令排列，当前后端要求标准顺序而拒绝。save 可以研究放宽到完整排列；set 不能直接删检查，因为固定版本 Qiskit/Aer 自身也能复现转译后逻辑结果变化。
