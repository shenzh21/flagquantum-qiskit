先说清楚，我们交付了什么

一个后端接口。
一条可以验证的计算链。

用户继续用 QuantumCircuit 描述实验；换成 FlagQuantumBackend 后，仍然用 transpile → run → result 完成计算。

目标

让 Qiskit 线路能够进入 FlagQuantum，并正确保留测量映射、参数、控制流和结果语义。

交付形态

flagquantum_qiskit 独立安装包、13 个源码模块、测试证据与文档；wheel 可从 0.2.0 源码构建。任务同步完成，job.result() 重复读取不会重新采样。

产品定位

一个连接两套框架的适配器。没有重写量子模拟器，也不是 AerSimulator(method="flagquantum") 插件，更不是完整 Aer 平替。

使用 · 完整 Bell 示例

保存为 bell_demo.py
from qiskit import QuantumCircuit, transpile
from flagquantum_qiskit import FlagQuantumBackend

backend = FlagQuantumBackend()
circuit = QuantumCircuit(2)
circuit.h(0)
circuit.cx(0, 1)
circuit.measure_all()

compiled = transpile(circuit, backend, seed_transpiler=7)
job = backend.run(
    compiled, shots=1000, seed_simulator=7, memory=True
)
result = job.result()
print(result.get_counts())

运行：.venv\Scripts\python.exe bell_demo.py。网页的复制按钮只复制文本，不调用后端。

transpile 到底改变了什么对象？

输入和输出都是 QuantumCircuit。转译过程中的 passes 常使用 DAGCircuit 分析和改写线路，但这并不意味着交给后端的对象变成了 FQ 程序。后端收到线路后，再做自己的校验与必要表示转换。

Target 是照抄 FlagQuantum 的原生门表吗？

不是。Target 表达的是本适配器已经接通的能力，既包含标准门，也包含由一般执行路径处理的初始化、矩阵、控制与保存指令。Target 允许转译器保留这些指令，实际类型、参数和资源限制仍由运行时检查。

backend.run 会再做一次完整转译吗？

不会自动替用户重复整套 Qiskit transpile 或 FQ plan/run。它做必要的校验和转换；初始化准备态会局部合成门序列。用户应先按目标能力准备线路，未知指令不会被静默跳过。

为什么 Bell 还不足以说明位序正确？看一个不对称例子。
实际位身份q0 = 1，q1 = 0
Qiskit 字符串高位在左，所以显示 01。若按 q0→c0、q1→c1 测量，经典结果也是 01。
状态数组的同一物理态Qiskit [0, 1, 0, 0]FQ [0, 0, 1, 0]
两边数组采用不同位序，因此在表示边界转换索引；量子位身份不反转，也不交换 CX 的控制位与目标位。


附带信息不是“可有可无”。
线路名称、metadata、经典寄存器、测量写入顺序、相位和 layout 会单独保留。数值样本需要按明确的 q→c 关系写回，未写经典位保持 0，重复写入以后一次为准。结果依据提交线路的真实位索引，不再把 layout 反转一次。

Aer 为什么仍然是可选依赖？
Aer 提供保存指令、NoiseModel 等对象，以及独立测试参考。生产可以使用它转换小规模局部通道的表示，但不调用 Aer 模拟器执行线路。基础 Bell、动态控制和通用 V2 包装器不需要 Aer。保存结果中的 Qiskit Statevector 只是容器，不是替代演化引擎。

这 190 项怎么算？
一次完整运行通过 186 项；随后针对初始化相位修复进行相关回归，累计覆盖 190 个不同用例。不是最终版本一次 190 项全量重跑；本页演示也不替代全套验收。
如何知道真在用 FQ？
测试追踪真实 FQ 采样与底层数值入口，并阻断替代模拟器的执行。wheel 安装后在包目录外验证；独立进程禁止 Aer 导入，基础 Bell 仍然成功。
17 条线路说明了什么？
原 QASM 没有测量，回归在副本中添加测量。它们在全零初态下都输出单一基态，不能证明任意输入的完整幺正等价。复振幅、相位、动态与噪声另有测试覆盖。
精确概率误差与有限 shots 的统计误差分开验收。原 17 条线路最大精确概率误差约 9.77 × 10⁻¹⁵；这是该组测试的结果，不是对任意线路的误差保证。
